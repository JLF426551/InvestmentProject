# InvestmentProject
Sample Python code to analyze mutual fund holding overlap by net assets.

**Sample Files**
xxxx_data.csv : Multiple files named with the Mutual Fund ticker in its name.
Code has a pre-loaded list of files that can be used for exploration.

**Code**
Code walks through sample analysis for a select group of mutual funds:
* Check number of holdings in top 33%
* Net assets % by top 25 holdings
* Matrix analysis of overlap holdings between mutual funds
